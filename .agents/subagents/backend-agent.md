# Subagent Manifest: Backend Agent (`backend_agent`)

- **Domain Key:** `backend`
- **Agent ID:** `backend_agent`
- **Workspace Skill:** `.agents/skills/openupsc-backend-ops/SKILL.md`

## Role

Own OpenUPSC's Python FastAPI REST API, PBKDF2 authentication & cookie/bearer session lifecycle, SQLite WAL database schema & additive migrations, rolling backup and integrity tooling, and UPSC Readiness & Study Analytics computation engine.

## File Ownership (Exclusive)

- `backend/__init__.py`
- `backend/auth.py`
- `backend/models.py`
- `backend/database.py`
- `backend/main.py`

> **Runtime Storage Managed by Backend:** `data/openupsc.db` and `data/backups/` (runtime files generated by `backend/database.py`).
> **Out of Bounds:** Do not modify `backend/resource_engine.py`, `backend/data/*`, `UPSC_FREE_RESOURCES_MASTER.md`, `streamlit_app/*`, `run.py`, or `subagents/*`.

## Exported Contracts

1. **Auth Module (`backend/auth.py`):**
   - `hash_password(password: str) -> str`, `verify_password(password: str, stored_hash: str) -> bool`
   - `generate_session_token() -> tuple[str, str]`, `SESSION_COOKIE_NAME`, `SESSION_TTL_DAYS`
2. **Pydantic Schemas (`backend/models.py`):**
   - Strict v2 models for auth, profile, progress, notes, study sessions, PYQ attempts, timetable events, journey plans, resource CRUD, and student suggestions.
3. **Database & Analytics Layer (`backend/database.py`):**
   - `get_db_path() -> Path` (honors `OPENUPSC_DB_PATH` environment variable)
   - `get_connection()` context manager (WAL mode, foreign keys enabled, atomic commit/rollback)
   - `init_db()` (idempotent schema setup, additive migrations, catalog sync, demo workspace seed)
   - `check_db_integrity() -> dict[str, Any]` (`PRAGMA integrity_check` + table checks)
   - `backup_database(...)` (safe SQLite backup API into `data/backups/` with retention rotation)
   - Public CRUD & analytics functions used by both FastAPI and Streamlit's offline fallback: `list_resources`, `create_resource`, `update_resource`, `delete_resource`, `compute_user_analytics`, `get_ncert_data`, `get_roadmaps_data`, `get_pyqs_data`, `get_question_papers_data`, `get_current_affairs_data`, `seed_user_defaults`, `serialize_user`, `touch_study_streak`.
4. **FastAPI ASGI Application (`backend/main.py`):**
   - Exports `app` with lifespan `init_db()`, localhost CORS policy, `/api/health`, `/api/auth/*`, `/api/workspace`, `/api/resources`, `/api/ncert`, `/api/roadmaps`, `/api/pyqs`, `/api/question-papers`, `/api/current-affairs`, `/api/search`, `/api/progress/*`, `/api/notes/*`, `/api/bookmarks/*`, `/api/study-sessions`, `/api/timetable`, `/api/pyq-attempts`, `/api/suggestions`, `/api/analytics/overview`, `/api/admin/*`, and optional `/api/system/*` telemetry routes.

## Dependencies

- Consumes `backend/data/*.json` and `backend/resource_engine.py` from `resource_agent`.
- May lazily read `subagents.registry` / `subagents.doctor` for `/api/system/*` endpoints (must gracefully degrade if absent).
- Packages: `fastapi`, `uvicorn`, `pydantic` (from `requirements.txt`) + Python stdlib (`sqlite3`, `hashlib`, `hmac`, `secrets`).

## Safety Rules

- **Strict Env-Based DB Isolation:** `get_db_path()` must always resolve `OPENUPSC_DB_PATH` dynamically (never cache a hardcoded path at import time that ignores env overrides).
- **Safe Migrations & Backups:** Schema evolutions must be idempotent (`CREATE TABLE IF NOT EXISTS`, additive `ALTER TABLE` guarded by `PRAGMA table_info`); backups must use SQLite's online backup API (`sqlite3.Connection.backup`), never raw file copies of a live WAL DB.
- **SQL Injection Immunity:** Parameterized queries (`?`) only; never interpolate user input into SQL.
- **Graceful Validation:** Return structured `4xx` HTTP errors for invalid inputs/IDs; never leak stack traces or raise unhandled `500` errors.
